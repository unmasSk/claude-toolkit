# Memory Index — unmassk-toolkit-ultron

## HARD RULE — read before touching git in this repo

**NEVER run `git stash`, `git reset`, `git checkout -- <path>`, `git restore`,
or ANY command that moves/mutates the working tree in `claude-toolkit` —
not even scoped to specific paths, not even "just to look."** Two sessions
of uncommitted work sit in this tree at the owner's own request (multiple
agents building in parallel, nothing committed yet) — one bad `stash`/
`reset`/`checkout` silently destroys days of someone else's work, not just
your own edit. This already happened twice in one session (see
[lessons.md](lessons.md), bottom section) and was only recovered by luck.

**For a before/after behavioral comparison instead:** copy the target
file(s) into the scratchpad dir, hand-edit the COPY to remove your change,
run the copy standalone. If it's a hook that does `sys.path.insert(0,
dirname(dirname(__file__)) + "/lib")`, put the copy at
`<scratch>/fake_repo/hooks/<file>.py` and symlink `<scratch>/fake_repo/lib`
→ the real `lib/` dir (and `<scratch>/fake_repo/.claude-plugin` → the real
one, if it reads `version.py`). This is the ONLY permitted way to get an
isolated "before" run. Read-only git (`status`, `diff`, `log`, `show`) is
always fine — the ban is on anything that moves the tree.
