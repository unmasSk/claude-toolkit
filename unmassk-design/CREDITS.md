# Credits

`unmassk-design` would not exist without prior open work. It fuses eight
sources into one core skill plus six family branches, each condensed and
rewritten in this plugin's own voice — see `PROVENANCE.md` for the
branch-by-branch mapping.

## Core

- **Impeccable** by Paul Bakaus (Apache 2.0) —
  https://github.com/pbakaus/impeccable. Aesthetic philosophy and the 10
  steering commands (`audit`, `critique`, `polish`, `bolder`, `quieter`,
  `animate`, `colorize`, `distill`, `harden`, `normalize`).
- **UI/UX Pro Max** by nextlevelbuilder (MIT) —
  https://github.com/nextlevelbuilder/ui-ux-pro-max-skill. Design-system
  generation workflow and the BM25 CSV corpus structure.
- **bencium-marketplace** by bencium.io (MIT) —
  https://github.com/bencium/bencium-marketplace. Plugin patterns folded
  into the core skill.

## design-motion

- **emilkowalski/skills** by Emil Kowalski (MIT) —
  https://github.com/emilkowalski/skills. Craft principles
  (`emil-design-eng`), Apple fluid-interfaces physics translated to the web
  (`apple-design`), the reverse-lookup animation vocabulary
  (`animation-vocabulary`), and the ten-point review bar
  (`review-animations` + `improve-animations`).
- **motion-dev-animations-skill** by 199-biotechnologies (MIT) —
  https://github.com/199-biotechnologies/motion-dev-animations-skill.
  Motion.dev (Framer Motion successor) API reference.
- **css-animation-skill** by neonwatty (MIT) —
  https://github.com/neonwatty/css-animation-skill. Trigonometric
  choreography and visibility patterns (`walkthrough-generator`).

## design-3d, design-scroll, design-animation-formats

- **claudedesignskills** by freshtechbro (Apache 2.0) —
  https://github.com/freshtechbro/claudedesignskills. A large community
  skill bundle; this plugin condenses 18 of its skills across three
  branches: 3D/WebGL engines and pipeline (design-3d), scroll-driven
  libraries (design-scroll), and animation formats/component libraries
  (design-animation-formats). Also contributes Framer Motion and React
  Spring physics patterns to design-motion.

## design-taste

- **taste-skill** by leonxlnx (MIT) —
  https://github.com/leonxlnx/taste-skill. Eight named aesthetic-direction
  skills (brutalist, minimalist, high-end/soft, redesign-to-premium,
  image-to-code, brand-kit generation) condensed into one family.

## design-flutter

- **claude-flutter-ui-skills** by Naimehossein77 (MIT) —
  https://github.com/Naimehossein77/claude-flutter-ui-skills. Flutter UI
  layout, Material 3/Cupertino theming, and animation patterns
  (`flutter-ui`), narrowed to this branch's design/UI scope.

## This plugin

`unmassk-design`'s own text (the routing, the reorganization, and the fused
method across all seven skills) is licensed MIT (see `README.md`).
