# Brand Kit: Logo Systems and Identity Boards

Source: `brandkit` skill by leonxlnx (MIT), condensed. For generating
brand-guidelines boards, logo systems, and identity decks -- distinct from
UI design; this is brand-system art direction.

## Core principle

A premium brand kit is not decoration -- it's a visual argument for why the
brand exists. Every board must answer: what does this brand represent?
What's the core metaphor? How does the logo express it? How does the
system scale across UI, print, image, and detail? Why does the whole thing
feel ownable?

## Strategy before visuals

Before generating anything, infer: category, audience, product function,
emotional promise, cultural position, trust level, symbolic metaphor, and
what the brand should explicitly avoid. Pick symbols from meaning, not
randomly -- e.g. a developer tool reaches for cursor/frame/bolt/scaffold;
security reaches for shield/eye/seal/protected-core; voice AI reaches for
waveform/orb/pulse-ring.

## Logo concept methods (use one, or combine two max)

1. **Monogram + meaning:** brand initial fused with a metaphor (e.g. `K` +
   kite/direction). Use negative space, cuts, or geometry -- not a plain
   letter icon.
2. **Product action:** turn the core action into an abstract symbol
   (build -> frame/scaffold; protect -> shield/boundary; speak ->
   waveform/pulse). Keep it abstract, not literal.
3. **Metaphor fusion:** combine two meaningful ideas into one reduced mark
   (owl + drone vision, shield + mountain, moon + waveform). Keep the
   fusion subtle and still readable.
4. **Negative space:** hidden arrow, protected center, cutout initial,
   internal path -- crisp, not muddy.
5. **Construction geometry:** circles, diagonal cuts, grids, modular
   blocks, orbital paths, crosshairs -- a mark built from a visible system.

Avoid: generic lightning bolts without justification, random animals, fake
luxury crests, copied famous marks, clipart-style icons, meaningless
sparkles, inconsistent variants across the board.

## Board composition (default 3x3 panel system)

1. Logo cover -- large logo/wordmark, minimal title, strong negative space.
2. Logo construction -- symbol breakdown, grid, or negative-space logic.
3. Digital application -- browser chrome, app header, terminal, or app icon.
4. Brand essence -- one short tagline, large readable type, sparse layout.
5. Color system -- swatches, gradient strips, palette cards.
6. Typography -- type specimen or primary/secondary pairing.
7. Physical application -- card, folder, badge, poster, seal, packaging.
8. Image direction -- cinematic landscape, product crop, editorial scene.
9. System detail -- UI chips, input bar, icon row, component strip.

Alternative: a 2x3 mini-deck (logo/wordmark, browser/product surface,
command/functional panel, atmosphere/campaign image, symbol/construction/
badge, tagline/system promise) for a leaner reference-style layout.

A board should have rhythm -- not every panel equally loud: alternate
quiet, functional, emotional, technical, atmospheric, and detailed panels.

## Visual modes (choose per brand category)

| Category | Visual cues | Logo logic | Mood |
|---|---|---|---|
| Dark developer/builder | near-black panels, monospace, terminal/prompt bars, cyan/lime accents | cursor+frame, bolt+speed, scaffold+monogram | precise, builder-native |
| Dark product/operator | black/dark-red/amber, glowing chips, segmented flows | signal, gift, path, switch | fast, tactical |
| Dark nature/calm system | deep green, lime accent, misty landscapes, soft overlays | path, leaf, moon, compass | calm, trustworthy |
| Dark security/threat intel | black/navy, shield forms, radar lines | shield, raptor, eye, boundary | serious, vigilant |
| Light editorial/compliance | warm ivory, paper texture, small serif labels, seals | seal, dog, shield, document | trustworthy, institutional |
| Luxury/beauty/fashion | ivory/stone/espresso, serif wordmark, embossing | monogram, seal, petal, vessel | tasteful, expensive |
| Voice/communication | dark indigo, lilac glow, waveform, mic motif | wave+initial, sound orb, speech path | fluid, intimate |
| Cultural/experimental | halftone, CRT texture, poster-style panels, bold accent | custom wordmark, icon with attitude | memorable, controlled |

## Premium detail language

Small page numbers, tiny footer labels, precise alignment marks,
construction lines, subtle crosshair grids, thin rules, browser bars,
image masks, low-opacity texture, one highlighted word, one accent chip.
Use sparingly -- premium detail should reward looking closer, not clutter
the board.

## Text and tagline rules

Use very little text: brand name, one tagline, one URL, one command,
2-5 section labels, short UI chips. No long paragraphs, no fake body copy,
no Lorem Ipsum. Taglines should be short and specific ("Build better.",
"On guard.") -- never generic corporate slogans or buzzword soup.

## Image and mockup direction

Images should be art-directed and match the palette/metaphor (cinematic
landscapes, halftone treatments, dark product closeups) -- never generic
stock people or cliche robot imagery. Mockups (browser chrome, terminal,
app icon, card stack, badge) are identity applications, not feature demos
-- avoid full fake dashboards with excessive data.

## Color discipline

One dominant palette: base + primary accent + secondary accent + neutrals.
Accents must repeat consistently across every panel. No random rainbow
unless explicitly requested; no generic purple-blue AI glow unless it's
genuinely appropriate to the brand.

## Anti-generic rules

Never: random floating icons, generic startup gradients, overdesigned
logos, meaningless blobs, messy layout collages, inconsistent logo marks
across panels, too many colors, cheap neon, stock-template brand boards,
soulless SaaS dashboards. The goal is quieter, sharper, more intentional --
not louder.
