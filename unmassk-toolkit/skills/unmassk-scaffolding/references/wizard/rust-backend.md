## Rust Backend

### Framework
- Axum *recommended*
- Actix Web
- Rocket

### Axum Features
- Async runtime (Tokio) *default*
- Database (SQLx + PostgreSQL)
- Tracing/logging
- Error handling (thiserror/anyhow)
- Configuration (config-rs)

### Actix Features
- Actor model
- WebSocket support
- High performance

### Rocket Features
- Request guards
- Fairings (middleware)
- Type-safe routing
