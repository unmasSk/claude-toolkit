## Testing Configuration

### Unit Testing
| Language | Options | Default |
|----------|---------|---------|
| JS/TS | Vitest, Jest | Vitest |
| Python | pytest, unittest | pytest |
| Go | Built-in, Testify | Built-in |
| Rust | Built-in | Built-in |

|------|----------|
