## Next.js Projects

### Version & Router
- Next.js 16+ App Router *recommended*
- Next.js Pages Router

### Features
- TypeScript *default*
- ESLint *default*
- Tailwind CSS *default*
- src/ directory *default*
- Turbopack

### Database/ORM
- None
- Prisma *recommended*
- Drizzle
- Supabase

### Authentication
- None
- NextAuth.js / Auth.js *recommended*
- Clerk
- Lucia
- Custom JWT

### API Style
- REST (Route Handlers)
- tRPC *recommended for full-stack*
- GraphQL (Apollo/Yoga)
