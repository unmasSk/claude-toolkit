## Browser Extensions

### Chrome Extension

#### Manifest Version
- Manifest V3 *required*

#### Features
- Popup UI
- Options page
- Background service worker
- Content scripts
- Side panel

#### UI Framework
- React + Vite *recommended*
- Vue + Vite
- Svelte
- Vanilla JS
- Plasmo framework

### Firefox Extension

#### Features
- WebExtension API
- Cross-browser compatibility
- Manifest V2/V3

### VS Code Extension

#### Extension Type
- Language support
- Themes/colors
- Snippets
- Commands/tools *default*
- Webview

#### Features
- TypeScript *default*
- Webview UI
- Language Server Protocol
- Testing setup

### Figma Plugin

#### Features
- TypeScript *recommended*
- UI (HTML/CSS or React)
- Figma API

### Obsidian Plugin

#### Features
- TypeScript *recommended*
- Obsidian API
- Settings tab
