## Libraries & Packages

### TypeScript NPM Package

#### Build Tool
- tsup *recommended*
- Rollup
- esbuild
- tsc only

#### Features
- ESM + CJS dual publish *recommended*
- TypeScript declarations
- Changesets (versioning)

#### Testing
- Vitest *recommended*
- Jest

### Python PyPI Package

#### Build Tool
- Hatch *recommended*
- Poetry
- Setuptools
- Flit

#### Features
- Type hints (py.typed)
- Multiple Python versions
- Documentation (mkdocs/sphinx)

#### Testing
- pytest *recommended*
- tox/nox (multi-version)

### Go Module

#### Features
- Semantic versioning
- Example tests
- Benchmarks

#### Documentation
- pkg.go.dev *default*
- GoDoc comments

### Rust Crate

#### Crate Type
- Library *default*
- Binary
- Proc-macro

#### Features
- Documentation (rustdoc)
- Feature flags
- no_std support
