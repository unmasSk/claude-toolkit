## Nuxt Projects

### Version
- Nuxt 3 *recommended*

### Features
- TypeScript *default*
- Auto-imports *default*
- ESLint *default*
- Tailwind CSS (@nuxtjs/tailwindcss)

### Rendering Mode
- Universal (SSR) *recommended*
- SPA (client-only)
- Static (SSG)
- Hybrid

### Modules
- @pinia/nuxt (state) *recommended*
- @nuxt/image
- @nuxt/content (for content sites)
- @sidebase/nuxt-auth

### API
- Nitro server routes *default*
- tRPC (@trpc-nuxt/client)
