## Svelte Projects

### Framework
- SvelteKit *recommended*
- Svelte (standalone)

### Features
- TypeScript *default*
- ESLint *default*

### CSS Framework
- Tailwind CSS *recommended*
- UnoCSS
- None

### State Management
- Svelte stores *default*
- None (props only)

### Rendering Mode (SvelteKit)
- SSR *default*
- SPA
- Static (prerender)

### Testing
- Vitest + Testing Library *recommended*
- Playwright (E2E)
