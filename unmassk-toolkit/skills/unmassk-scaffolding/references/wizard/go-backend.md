## Go Backend

### Framework
- Gin *recommended*
- Fiber
- Echo
- Chi
- Standard library (net/http)

### Project Structure
- Simple (single main.go)
- Standard (internal/, cmd/, pkg/) *recommended*
- Domain-driven

### Database
- None
- PostgreSQL *recommended*
- MySQL
- MongoDB
- SQLite

### ORM/Query Builder
- sqlc (type-safe SQL) *recommended*
- GORM
- sqlx
- Ent

### Features
- JWT authentication
- Rate limiting
- Swagger/OpenAPI (swaggo)
- Graceful shutdown
